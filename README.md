# Hi, I'm Mariah 👋

Support Operations & Tooling | SQL · Python · Workflow Automation

I lead a global support organization and spend a lot of my time at the intersection of operations and engineering — identifying manual workflows, building tooling to eliminate them, and designing systems that scale.

Most of my work lives in private company repositories, but the types of problems I solve include:

- Automated configuration monitoring pipelines that diff external specs against internal system state and generate remediation workflows
- Self-service web UIs on top of stored procedures that remove manual handoffs between support and engineering
- Operational dashboards and analytics for incident trending, SLA compliance, and escalation pattern analysis
- Python jobs for data extraction, comparison, and automated ticket creation

I'm not a software engineer by title, but I build things that make operations teams faster and less dependent on engineering bandwidth.
